# Gestion des étudiants

## Présentation

Ce projet consiste à développer une application Python de gestion des étudiants.

## Objectifs

- Ajouter des étudiants.
- Afficher les informations des étudiants.
- Organiser les fonctionnalités de l'application.
- Utiliser Git pour suivre les modifications du projet.

## Technologies utilisées

- Python
- Git
- GitHub
- Docker

## Auteur

Projet réalisé dans le cadre du devoir pratique sur le terminal et la documentation Git.
